# FR3→FR5 전이 연구 — 자료 추출 요청서

이 문서를 받은 채팅은 아래 템플릿을 채워 **하나의 Markdown 보고서**로 돌려준다.

## 배경
7-DoF Franka FR3에서 수집한 데이터를 6-DoF FAIRINO FR5 정책 학습에 co-training으로 섞는 연구다.
두 로봇 모두 같은 태스크 구성·명령문으로 수집했고, FR5 쪽 테이블이 더 작다.
두 데이터를 공통 EE / task-frame 표현으로 변환하기 위해 아래 정보가 필요하다.

## 작성 규칙
1. 이 채팅의 대화·첨부 파일·실행 결과로 확인되는 것만 쓴다. 그럴듯한 값으로 빈칸을 채우지 않는다.
   모르면 `[확인 필요]`와 함께 **무엇을 보면 알 수 있는지**를 적는다.
2. 값마다 태그를 붙인다.
   `[확인]` 파일·출력·실측으로 직접 확인 · `[정황확인]` 강한 정황, 원문 미확인 · `[추론]` 근거 기반 해석 · `[확인 필요]` 미검증
3. 값마다 출처(파일 경로, 코드 위치, 대화 시점, 실행 명령)를 괄호로 붙인다.
4. 단위와 규약을 반드시 명시한다: rad/deg, m/mm, quaternion 순서(xyzw/wxyz), Euler 순서, 기준 좌표계.
5. 셸 접근이 있으면 추측하지 말고 파일을 열어 확인한다. 사용한 명령과 출력 요약은 부록에 남긴다.
   파일을 수정·이동·삭제하지 않는다.
6. 이 채팅이 FR3·FR5 중 한쪽만 다뤘다면 그쪽만 작성하고 나머지는 "해당 없음"으로 둔다.
7. ★ 항목이 최우선이다. 시간이 부족하면 ★부터 채운다.
