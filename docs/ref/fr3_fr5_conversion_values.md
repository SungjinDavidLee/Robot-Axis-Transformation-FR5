# FR3 ↔ FR5 변환값 정리

2026-09-28 기준. FR5 실물 205판 수집과 GR00T 롤아웃에 실제로 쓰고 있는 값이다.
표시가 없는 것은 측정·검증을 거친 값이고, 잠정값은 그렇게 적었다.

---

## 1. 좌표계

FR5 베이스를 **z축 기준 −77.2°** 회전한 것이 작업 프레임이다. 데이터의 모든 위치·자세는 이 프레임 기준이다.

```
x_w =  x_b·cos(77.2°) + y_b·sin(77.2°)
y_w = −x_b·sin(77.2°) + y_b·cos(77.2°)
z_w =  z_b
```

코드에서는 회전 행렬로 둔다.

```python
R_TASK     = rz(-77.2)   # base -> task
R_TASK_INV = rz(+77.2)   # task -> base
```

제어기가 주는 자세각 `rx, ry, rz` 는 **고정축 XYZ** 규약이다.

```
R = Rz(rz) · Ry(ry) · Rx(rx)
```

## 2. 공구(TCP)

```
tool 1 = 플랜지에서 공구축 방향 +z 167.6 mm,  회전·측면 성분 0
```

관절각과 제어기 TCP 로 역산하면 **167.87 mm** 로 설정값과 0.3 mm 차이다.
캘리퍼 실측은 아직 안 했다(잠정값).

---

## 3. 기구학 (FR5, UR 계열 표준 DH)

```
d1 = 152,  a2 = -425,  a3 = -395,  d4 = 102,  d5 = 102,  d6 = 100   [mm]
alpha = [+90, 0, 0, +90, -90, 0]  [deg]
```

이 값으로 계산한 TCP 가 실측 3자세와 **0.4 mm 이내**로 일치한다.
수치 역기구학(자코비안 감쇠최소자승)은 실제 롤아웃 크기의 목표 300회에서
최대 오차 0.019 mm, 0.8 ms/회.

---

## 4. 그리퍼 (DH AG-95)

```
위치 0 ~ 1000  →  반폭 0 ~ 0.04 m        grip_width[m] = pos/1000 × 0.04
힘   20 ~ 100 %  (레지스터 0x0101)
상태 1 도달 / 2 물체에 걸림 / 3 놓침
```

수집 시작 시점 그리퍼는 205판 모두 **pos 1000 (= 0.04 m, 완전 열림)** 이다.

---

## 5. 데이터 규약 (FR3 `task6_franka_v5` 와 동일)

```
observation.state  8차원 = x, y, z, aa1, aa2, aa3, gripper, −gripper
                   위치 m, 회전 축각, 그리퍼 반폭 m
action             7차원 = 다음 프레임의 절대 state 앞 7개
                   마지막 프레임은 자기 자신
영상               observation.images.image / observation.images.wrist_image
                   848×480 → 256×256 BILINEAR, 크롭·반전 없음
```

FR3 의 `task6_franka_v5` 와 대조해 **action[t] = state[t+1][:7] 이 오차 0** 으로 일치함을 확인했다.

축각 정규화 (판 첫 프레임 기준으로 가까운 표현 선택)

```
ref_axis_angle = [-2.4425330290871115, 1.968073832566227, 0.0019828086840627443]
scale_trans = 0.0356    scale_rot = 0.0665     (롤아웃 역변환 참고용, 학습에는 불필요)
```

주의 — 이 정규화는 축각 크기가 π 부근일 때 인접 프레임이 서로 다른 표현으로 갈릴 수 있다.
회전 라벨이 깨졌을 가능성이 있어 현재 롤아웃은 회전을 시작 자세로 고정하고 위치·그리퍼만 쓴다.

## 6. 두 로봇의 손끝 자세 차이

```
FR3 작업프레임 축각   (3.1224, -0.0048, -0.0061)
FR5 작업프레임 축각   (2.4349, -1.9806, -0.0915)
```

접근축(아래 방향)은 같고, **그 축 둘레로 약 77° 차이**다. FR5 쪽 그리퍼 방향이 물리적으로
자연스러워 그대로 썼다. FR3 궤적을 FR5 로 재생하거나 그 반대로 쓸 때는 이 값만큼 보정해야 한다.

---

## 7. 파지점과 물체 중심의 차이 (2026-09-28 실측)

로그의 파지 좌표는 **그릇 중심이 아니라 접시 쪽 테두리**다. 13판으로 잰 치우침:

```
파지 지점 − 그릇 중심 =  x −11 ± 23 mm,   y −70 ± 15 mm
```

그릇 반지름이 60 mm 이므로 y 치우침은 반지름과 같은 크기다.
**데이터의 파지 좌표를 물체 중심으로 쓰면 7 cm 어긋난다.** 평가 배치를 만들 때는 +70 mm 보정이 필요하다.

## 9. 태스크 위치 분포 (205판, 10 / 50 / 90 백분위)

```
파지 지점   x 0.566 0.625 0.683    y 0.148 0.201 0.349    z 0.048 0.059 0.069
배치 지점   x 0.690 0.728 0.765    y -0.008 0.029 0.094   z 0.083 0.101 0.118
들어올린 최고 높이 z 중앙 0.212
파지 순간 시작 자세 대비 회전 중앙 16.3° (90% 29.9°)
```

7절의 보정을 적용하면 **그릇 중심**은 위 파지 지점에서 y +70 mm, **접시 중심**은 배치 지점에서 y +70 mm 자리가 된다.
