# 인계 — FR3 ↔ FR5 데이터 전이

다른 대화에서 이 작업을 이어갈 때 필요한 것만 모았다. 자세한 수치는
`fr3_fr5_conversion_values.md` 와 `FR5-GR00T-Benchmark/docs/` 에 있다.

---

## 1. 지금까지 확정된 것

```
액션 규약      FR5 데이터 = FR3 task6_franka_v5 와 동일
               action[t] = state[t+1][:7],  205판 전체에서 오차 0.000000 확인
상태           8차원 x, y, z, aa1, aa2, aa3, gripper, -gripper
영상           observation.images.image / wrist_image, 848x480 -> 256x256, 크롭·반전 없음
```

**두 로봇 데이터를 섞거나 한쪽에서 다른 쪽으로 옮길 때 형식 변환은 필요 없다.**
필요한 것은 좌표계 보정뿐이다.

## 2. 보정해야 하는 것

```
작업 프레임     FR5 = 베이스를 z축 -77.2° 회전
손끝 자세 차이   FR3 축각 (3.1224, -0.0048, -0.0061)
                FR5 축각 (2.4349, -1.9806, -0.0915)
                접근축은 같고 그 축 둘레로 약 77° 차이
파지점 보정      기록된 파지 좌표는 그릇 중심이 아니라 접시 쪽 테두리
                파지 지점 - 그릇 중심 = x -11 ± 23 mm, y -70 ± 15 mm  (FR5 13판 실측)
                FR3 쪽도 같은 성질인지 확인이 필요하다
```

## 3. 물리 규격 차이

```
            FR3                         FR5
자유도       7                           6
그리퍼       Franka Hand                 DH AG-95 (반폭 0~0.04 m, 힘 20~100 %)
파지 폭      0.0036 m (파지 후)           0.0040~0.0056 m
파지 높이    0.0875 m (std 7.3 mm)       0.059 m (10~90 % 0.048~0.069)
배치 높이    0.1052 m                    0.101 m
회전 처리    컨트롤러가 회전 명령 폐기       정책 회전 미사용 (학습 신호 없음)
```

높이 기준이 다른 것은 **작업대와 공구 길이가 다르기 때문**이며, 그대로 옮기면 안 된다.

## 5. 먼저 확인할 것

1. **FR3 데이터의 파지 좌표도 테두리인가** — 그릇 중심 대비 치우침을 재야 두 데이터를
   같은 기준으로 놓을 수 있다
2. **FR3 작업 프레임 정의** — FR5 는 -77.2° 회전이 명시돼 있다. 그쪽 기준을 받아 적는다
3. **섞을 것인가 옮길 것인가** — 두 로봇 데이터를 한 데이터셋으로 학습할지, FR3 로 학습한
   정책을 FR5 에서 돌릴지에 따라 필요한 보정이 다르다

## 6. 주의

- FR5 쪽 30판 성공률 43.3 % 는 **불리한 하네스 설정에서 나온 값**이다. 같은 배치로
  재측정하면 올라갈 가능성이 크다(절제 실험 10판에서 9/10). 전이 실험의 기준선으로 쓰려면
  재측정 뒤 숫자를 쓰는 편이 낫다.
- FR5 정책의 공간 추종이 0.35 다. 전이 실험에서 성능이 낮게 나와도 전이 실패인지
  원래 한계인지 구분하려면 이 값을 기준으로 삼아야 한다.
